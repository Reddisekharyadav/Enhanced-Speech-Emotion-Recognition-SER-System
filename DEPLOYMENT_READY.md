## 🐛 Troubleshooting:

### "App is sleeping"
- Apps sleep after inactivity (free tier)
- Wakes up when someone visits (takes ~30 seconds)
- Solution: Share link often to keep it warm

### "Requirements error"
- Check `requirements_streamlit.txt` has all packages
- Make sure it's named exactly: `requirements_streamlit.txt` or `requirements.txt`

### "Model not found"
- Ensure model files are pushed to GitHub:
  ```powershell
  git add ser/models/*.keras
  git add ser/models/*.pkl
  git commit -m "Add model files"
  git push
  ```
